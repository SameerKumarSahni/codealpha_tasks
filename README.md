# CodeAlpha Python Internship Tasks

This repository contains the Python projects completed as part of my CodeAlpha Internship.

The projects demonstrate fundamental Python programming concepts including functions, loops, conditional statements, dictionaries, file handling, regular expressions, and basic automation.

---

## 📁 Projects

### 1. Hangman Game

A simple console-based Hangman game where the player attempts to guess a randomly selected word one letter at a time.

**Features:**
- Predefined list of words
- Random word selection
- Letter-by-letter guessing
- Maximum of 6 incorrect guesses
- Input validation
- Duplicate guess detection
- Win and lose conditions

**Concepts Used:**
- `random`
- Lists
- Strings
- `while` loop
- `for` loop
- `if-elif-else`
- User input

**Run:**

```bash
python hangman.py



##2. Stock Portfolio Tracker
